# Specifications

This directory owns accepted normative NKF format and profile specifications.

[`nkf-0.1.md`](nkf-0.1.md) is the accepted canonical NKF 0.1 Product
specification. ADR 0029 accepts its current exact revision and digest-bound
YAML companion under delegated technical authority. ADR 0030 confirms the
current exact source-bound JSON Schemas. ADRs 0010, 0022, and 0027 and the
Studio source baseline remain immutable historical provenance.
