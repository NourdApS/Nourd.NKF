## Findings Repaired Before Confirmation

### Normative Diagnostic Registry

The accepted executable companion and checker contained eight topology
diagnostics absent from the normative Markdown diagnostic table. ADR 0073
corrected the accepted authority pair and all derived source bindings.

### Circular Authoring And Release Gate

The authoring command required the current candidate to match the previously
published recommendation, making pre-release validation impossible. ADR 0074
separated current-snapshot authoring validation from explicit release review
without weakening either check.

### Repair Receipt Integrity

The repair path shape-checked predecessor and successor receipts too loosely.
It now requires exact receipt keys, safe unique and disjoint path partitions,
profile and knowledge-root agreement, and exact archive, source, checker, and
adopter lineage for both repair and no-update outcomes. Tamper tests cover the
new fail-closed boundaries.

### Navigation And Current-State Accuracy

Current indexes, Specification guidance, Task progress, and consolidated
Realization references were reconciled to the corrected authority pair and
the completed successor. Historical Evidence remains unchanged.
