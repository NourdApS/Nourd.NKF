# Evidence

This directory contains governed evidence needed for NKF design, conformance,
compatibility, and migration decisions. Evidence does not become normative
merely because it is retained here.

## Collections

- [`source-snapshots/`](source-snapshots/) preserves exact earlier-authority
  sources with commit and digest provenance.
- [`nkf-003-source-reconciliation.md`](nkf-003-source-reconciliation.md)
  records the verified migration inventory, authority classification, and
  unresolved compatibility boundaries for Task `NKF-003`.
