# Evidence

Evidence preserves reviewed facts, source material, audits, migration inputs,
and historical artifacts needed to evaluate NKF work. Evidence does not become
normative, accepted, adopted, confirmed, or conformant merely because it is
retained.

Evidence files are exempt from repository front-matter and timestamp
normalization so original bytes and historical precision can be preserved.

## Audits

[`audits/`](audits/) contains the pre-remediation repository audit, NKF-007
inventory and classification reviews, the front-matter parser finding, and
authority-pair, NKF-011 enforcement, NKF-008 release, public-documentation,
consumer-workflow, NKF-013 completion, and NKF-015 agent-led onboarding audit
evidence. It also contains the whole-repository development-support audit
covering agent guidance, human and Knowledge Engine consumption, monolithic
applications, coherence, completeness, enforcement, and current readiness,
plus the NKF-015 exact public-projection publication and fresh-clone
verification Evidence.

## Decision Inputs

[`decision-inputs/`](decision-inputs/) preserves historical Specification
revisions, executable contract candidates, Schema proposals, validation
examples, and exact Design or migration-map inputs grouped by the Decisions
that reviewed them.

## Source Snapshots

[`source-snapshots/`](source-snapshots/) preserves exact earlier-authority
sources with repository commit and digest provenance.

## Migration Reconciliation

[NKF-003 Source Reconciliation](nkf-003-source-reconciliation.md) records the
verified source inventory, authority classification, and unresolved
provenance limitations from the independent-repository migration.
