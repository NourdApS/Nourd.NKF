# Evidence

Evidence preserves reviewed facts, source material, audits, migration inputs,
and historical artifacts needed to evaluate NKF work. Evidence does not become
normative, accepted, adopted, confirmed, or conformant merely because it is
retained.

Evidence files are exempt from repository front-matter and timestamp
normalization so original bytes and historical precision can be preserved.

compatibility, documentation, and recovery review of the exact successor. The
NKF-019 Nourd Tiles decision applicability failure Evidence binds the

Gate. The NKF-020 complete-set release audit independently verifies exact

Evidence records the later GitHub prerelease, independent re-download,

The NKF-023 NKF 0.3 producer-adoption audit records the first pristine-clone
