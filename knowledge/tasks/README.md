# Tasks

Tasks own durable work intent, constraints, acceptance criteria, and execution
plans. Task status lives in the stable YAML document declaration; the
generated state indexes below are its navigation projection, and canonical
Task sources stay at their neutral `items/` paths through every lifecycle
transition. This page does not duplicate lifecycle state: the generated
indexes are the current listing for every state.
