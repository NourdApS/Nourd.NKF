# Code Of Conduct

This repository is maintained by Nourd ApS and is open to anyone who engages
respectfully with the work and the people doing it.

## Expected Behaviour

- Argue about evidence, specifications, and code, not about people.
- State disagreement plainly and without contempt.
- Assume good faith and ask before concluding.
- Respect the governed process described in `CONTRIBUTING.md`, including that
  some changes require a Task and a Decision before they can be merged.

## Unacceptable Behaviour

- Harassment, personal attacks, or discriminatory language in any form.
- Publishing another person's private information without consent.
- Sustained disruption of issues, pull requests, or discussions after being
  asked to stop.

## Reporting And Enforcement

Report conduct concerns to the repository maintainers through a Github issue if
the matter is not sensitive, or through Github's private vulnerability reporting
on this repository if it is. Reports are handled by Nourd ApS. Responses range
from a private request to change behaviour to removal from the repository's
issues and pull requests, at the maintainers' judgment.

This document applies to all interaction in this repository's issues, pull
requests, discussions, and commits.
